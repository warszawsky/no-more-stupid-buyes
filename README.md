# No More Stupid Buys

> **⛔ Не доступно для пользователей из России и Беларуси.**

Пиксельная качка в бандане живёт у тебя над панелью задач. Пока ты работаешь, она бродит, сидит и спит. Стоит открыть Rozetka, Prom, OLX, AliExpress, Temu или Amazon, как она подбегает и говорит:

> **You got 5 seconds to leave this page.**
> Or else.

И достаёт пистолет. Закрыл вкладку вовремя: качка тебя хвалит. Не закрыл: она говорит «Fine. I'll do it myself», взлетает к вкладке и закрывает её клювом. Можно переключить на старый вариант, где она просто стреляет.

Идея взята из ролика про [Desktop Duck](https://store.steampowered.com/search/?term=desktop+duck) (это платная игра в Steam). Здесь своя реализация той же механики: качка нарисована с нуля, код открытый, всё бесплатно.

## Установка

### Windows (готовый .exe)

1. Открой вкладку **Actions** в этом репозитории, выбери последний зелёный запуск `build` и скачай артефакт `no-more-stupid-buys-windows`. Если есть релиз (тег `v*`), установщик лежит во вкладке **Releases**.
2. Внутри два файла: `No More Stupid Buys Setup x.y.z.exe` (установщик) и `No More Stupid Buys x.y.z.exe` (portable, работает без установки).
3. Приложение не подписано, поэтому Windows SmartScreen скажет «Windows защитила ваш компьютер». Жми **Подробнее → Выполнить в любом случае**.

После запуска качка падает сверху на панель задач, а в трее появляется её голова. Правый клик по иконке в трее (или по самой качке) открывает меню.

### Из исходников (Windows, macOS, Linux)

Нужен Node.js 20+.

```bash
npm install
npm start
```

Собрать свой установщик: `npm run dist:win`, `npm run dist:mac` или `npm run dist` (под текущую систему). Результат будет в `dist/`.

## Как качка понимает, что ты шопишься

**Без расширения (по умолчанию).** Раз в 0.7 секунды приложение смотрит, какое окно сейчас активно. Если это браузер (Chrome, Edge, Firefox, Opera, Brave, Vivaldi, Arc, Safari) и в заголовке вкладки есть название магазина, значит, ты в магазине. Заголовки поиска Google, YouTube, Википедии и т.п. игнорируются, так что видео «огляд дивана з Rozetka» качку не разозлит.

Вкладку она закрывает нажатием Ctrl+W (Cmd+W на Mac) в активном окне. Само окно качки фокус никогда не забирает, так что Ctrl+W уходит именно в браузер.

**С расширением (точнее).** Расширение сообщает качке настоящий адрес вкладки и её место в ряду вкладок, а закрывает вкладку само, без эмуляции клавиш. Так ловятся и магазины, у которых в заголовке нет названия, а качка летит точно к крестику нужной вкладки. Ставится один раз:

1. В меню качки выбери **Browser extension (more accurate)...**, откроется папка с расширением. Из исходников это папка `extension/`.
2. Открой `chrome://extensions` (в Edge `edge://extensions`).
3. Включи **Режим разработчика**, нажми **Загрузить распакованное** и выбери эту папку.

Когда расширение подключено, в меню рядом с этим пунктом появляется ✓. Расширение общается только с приложением на твоём компьютере (`127.0.0.1:47821`), в интернет ничего не уходит. Чужие сайты подключиться к качке не могут: принимаются только соединения от расширений.

Без расширения качка не знает, какая по счёту вкладка открыта, и летит к первой. Закроется всё равно та вкладка, на которую ты смотришь.

### Какие магазины она знает

- **Украина:** Rozetka, Prom.ua, OLX, Епіцентр, Comfy, Фокстрот, АЛЛО, MOYO, Kasta, MAKEUP, EVA, Intertop, Answear, Shafa.
- **Остальной мир:** Amazon (все страны), eBay, AliExpress, Temu, SHEIN, Etsy, Walmart, Target, Best Buy, iHerb, ASOS, Joom, магазин Steam.

Российских маркетплейсов в списке нет.

## Меню

Качка и меню говорят только по-английски.

- **Show me what you do (demo).** Прогоняет всю сцену без настоящей вкладки.
- **I really need to buy something.** Пауза на 15 минут, на час или до перезапуска. Качка прокомментирует.
- **When time runs out:** взлететь и закрыть вкладку клювом (по умолчанию), выстрелить и закрыть или только угрожать.
- **Countdown:** 3, 5 или 10 секунд.
- **Duck size, Sound.**
- **Start with system** (Windows и macOS).
- **Open settings file.**

Качку можно тыкать (она крякает) и таскать мышкой. Пока открыта полноэкранная игра или видео, она прячется.

## Настройки

Файл `settings.json` лежит в папке приложения:

- Windows: `%APPDATA%\No More Stupid Buys\settings.json`
- macOS: `~/Library/Application Support/No More Stupid Buys/settings.json`
- Linux: `~/.config/No More Stupid Buys/settings.json`

Изменения подхватываются на лету. Добавить свой магазин или выключить встроенный:

```json
{
  "customStores": [
    { "name": "Zara", "domains": ["zara.com"], "keywords": ["ZARA"] }
  ],
  "disabledStores": ["Steam", "OLX"]
}
```

`domains` проверяются по настоящему адресу (с расширением или на macOS), `keywords` ищутся в заголовке окна с учётом регистра и целыми словами. Окончания учитываются: `Фокстрот` ловит и «у Фокстроті».

## Особенности платформ

- **Windows.** Основная платформа, всё работает из коробки, включая масштабирование экрана 125% и 150%.
- **macOS.** Для чтения адреса вкладки и для Cmd+W системе нужно дать приложению доступ в **Настройки → Конфиденциальность и безопасность → Универсальный доступ**. Сборка не подписана: при первом запуске открывай через правый клик → «Открыть», а если macOS пишет, что приложение повреждено, выполни `xattr -cr "/Applications/No More Stupid Buys.app"`.
- **Linux (X11).** Нужны `xprop`, `xwininfo` (пакет `x11-utils`) и `xdotool`. Окно качки пропускает клики насквозь, поэтому на Linux её нельзя тыкать и таскать, меню доступно только через трей. Wayland не поддерживается.

## Честно о том, чего качка не умеет

- По заголовку окна не узнать магазин, если его названия в заголовке нет. Для таких случаев ставь расширение или добавь ключевое слово в настройки.
- Место крестика вкладки она угадывает по размеру окна и числу вкладок. В Chrome и Edge попадает, в браузерах с другой раскладкой вкладок может клюнуть рядом. Закрывается при этом всё равно нужная вкладка.
- Если браузер открыт на втором мониторе, качка туда не летит и вместо этого стреляет.
- Покупки с телефона она не видит.
- Купить, если очень хочется, она не мешает: есть пауза. Смысл в том, чтобы сбить импульс, а не запереть тебя.

## Для разработчиков

```bash
npm test                                   # юнит-тесты детектора магазинов и логики
npm start -- --simulate-window=win.json    # «активное окно» читается из JSON-файла
npm start -- --self-test=report.json       # запуск, самопроверка, отчёт, выход (используется в CI)
```

Пример `win.json`: `{"title": "Диван – купити | ROZETKA - Google Chrome", "owner": {"name": "Google Chrome", "path": "chrome.exe"}}`.

Устройство:

- `src/main/` — главный процесс Electron: прозрачное окно-полоска над панелью задач (во время полёта растягивается на весь экран), трей, слежение за окнами (`watcher.js`), распознавание магазинов (`matcher.js`, `stores.js`), прицел для клевка (`tabs.js`), закрытие вкладки (`punish.js`), мост для расширения (`bridge.js`).
- `src/renderer/` — качка: анимации, поведение, пузырь с текстом, звуки (синтезируются через WebAudio, файлов нет).
- `src/shared/duck-art.js` — качка рисуется кодом по пикселям; из этого же кода делаются иконки (`npm run icons`).
- `extension/` — расширение для Chromium-браузеров.

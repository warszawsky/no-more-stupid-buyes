# No More Stupid Buys

Пиксельная утка в бандане живёт у тебя над панелью задач. Пока ты работаешь, она бродит, сидит и спит. Стоит открыть Amazon, OZON, Wildberries или AliExpress, как она подбегает и говорит:

> **У тебя 5 секунд, чтобы свалить с этой страницы.**
> Иначе пожалеешь.

И достаёт пистолет. Закрыл вкладку вовремя: утка тебя хвалит. Не закрыл: стреляет и сама закрывает вкладку.

Идея взята из ролика про [Desktop Duck](https://store.steampowered.com/search/?term=desktop+duck) (это платная игра в Steam). Здесь своя реализация той же механики: утка нарисована с нуля, код открытый, всё бесплатно.

## Установка

### Windows (готовый .exe)

1. Открой вкладку **Actions** в этом репозитории, выбери последний зелёный запуск `build` и скачай артефакт `no-more-stupid-buys-windows`. Если есть релиз (тег `v*`), установщик лежит во вкладке **Releases**.
2. Внутри два файла: `No More Stupid Buys Setup x.y.z.exe` (установщик) и `No More Stupid Buys x.y.z.exe` (portable, работает без установки).
3. Приложение не подписано, поэтому Windows SmartScreen скажет «Windows защитила ваш компьютер». Жми **Подробнее → Выполнить в любом случае**.

После запуска утка падает сверху на панель задач, а в трее появляется её голова. Правый клик по иконке в трее (или по самой утке) открывает меню.

### Из исходников (Windows, macOS, Linux)

Нужен Node.js 20+.

```bash
npm install
npm start
```

Собрать свой установщик: `npm run dist:win`, `npm run dist:mac` или `npm run dist` (под текущую систему). Результат будет в `dist/`.

## Как утка понимает, что ты шопишься

**Без расширения (по умолчанию).** Раз в 0.7 секунды приложение смотрит, какое окно сейчас активно. Если это браузер (Chrome, Edge, Firefox, Яндекс, Opera, Brave, Vivaldi, Arc, Safari) и в заголовке вкладки есть название магазина, значит, ты в магазине. Заголовки поиска Google/Яндекса, YouTube, Википедии и т.п. игнорируются, так что видео «обзор дивана с Amazon.com» утку не разозлит.

Закрывает вкладку она нажатием Ctrl+W (Cmd+W на Mac) в активном окне. Само окно утки фокус никогда не забирает, так что Ctrl+W уходит именно в браузер.

**С расширением (точнее).** Расширение сообщает утке настоящий адрес вкладки и закрывает её само, без эмуляции клавиш. Так ловятся и магазины, у которых в заголовке нет названия. Ставится один раз:

1. В меню утки выбери **«Расширение для браузера (точнее)...»**, откроется папка с расширением. Из исходников это папка `extension/`.
2. Открой `chrome://extensions` (в Edge `edge://extensions`, в Яндексе `browser://extensions`).
3. Включи **Режим разработчика**, нажми **Загрузить распакованное** и выбери эту папку.

Когда расширение подключено, в меню рядом с этим пунктом появляется ✓. Расширение общается только с приложением на твоём компьютере (`127.0.0.1:47821`), никуда в интернет ничего не уходит. Чужие сайты подключиться к утке не могут: принимаются только соединения от расширений.

### Какие магазины она знает

Amazon (все страны), eBay, AliExpress, Temu, SHEIN, Etsy, Walmart, Target, Best Buy, iHerb, ASOS, Joom, OZON, Wildberries, Яндекс Маркет, Мегамаркет, Lamoda, Авито, М.Видео, Эльдорадо, DNS, Ситилинк, Kaspi, Rozetka и магазин Steam.

## Меню

- **Покажи, что ты умеешь (демо).** Прогоняет всю сцену без настоящей вкладки.
- **Мне правда надо кое-что купить.** Пауза на 15 минут, на час или до перезапуска. Утка прокомментирует.
- **Когда время вышло:** закрыть вкладку или только угрожать.
- **Отсчёт:** 3, 5 или 10 секунд.
- **Размер утки, звук, язык** (русский/английский, по умолчанию берётся язык системы).
- **Запускать вместе с системой** (Windows и macOS).
- **Открыть файл настроек.**

Утку можно тыкать (она крякает) и таскать мышкой.

## Настройки

Файл `settings.json` лежит в папке приложения:

- Windows: `%APPDATA%\No More Stupid Buys\settings.json`
- macOS: `~/Library/Application Support/No More Stupid Buys/settings.json`
- Linux: `~/.config/No More Stupid Buys/settings.json`

Изменения подхватываются на лету. Добавить свой магазин или выключить встроенный:

```json
{
  "customStores": [
    { "name": "Zara", "domains": ["zara.com"], "keywords": ["ZARA"] }
  ],
  "disabledStores": ["Steam", "Авито"]
}
```

`domains` проверяются по настоящему адресу (с расширением или на macOS), `keywords` ищутся в заголовке окна с учётом регистра и целыми словами. Русские окончания учитываются: `Яндекс Маркет` ловит и «на Яндекс Маркете».

## Особенности платформ

- **Windows.** Основная платформа, всё работает из коробки.
- **macOS.** Для чтения адреса вкладки и для Cmd+W системе нужно дать приложению доступ в **Настройки → Конфиденциальность и безопасность → Универсальный доступ**. Сборка не подписана: при первом запуске открывай через правый клик → «Открыть», а если macOS пишет, что приложение повреждено, выполни `xattr -cr "/Applications/No More Stupid Buys.app"`.
- **Linux (X11).** Нужны `xprop`, `xwininfo` (пакет `x11-utils`) и `xdotool`. Окно утки пропускает клики насквозь, поэтому на Linux её нельзя тыкать и таскать, меню доступно только через трей. Wayland не поддерживается.

## Честно о том, чего утка не умеет

- По заголовку окна не узнать магазин, если его названия в заголовке нет. Для таких случаев ставь расширение или добавь ключевое слово в настройки.
- Покупки с телефона утка не видит.
- Она не мешает купить, если очень хочется: есть пауза. Смысл в том, чтобы сбить импульс, а не запереть тебя.

## Для разработчиков

```bash
npm test                                   # юнит-тесты детектора магазинов и логики
npm start -- --simulate-window=win.json    # «активное окно» читается из JSON-файла
npm start -- --self-test=report.json       # запуск, самопроверка, отчёт, выход (используется в CI)
```

Пример `win.json`: `{"title": "Amazon.com: Gorilla couch - Google Chrome", "owner": {"name": "Google Chrome", "path": "chrome.exe"}}`.

Устройство:

- `src/main/` — главный процесс Electron: прозрачное окно-полоска над панелью задач, трей, слежение за окнами (`watcher.js`), распознавание магазинов (`matcher.js`, `stores.js`), закрытие вкладки (`punish.js`), мост для расширения (`bridge.js`).
- `src/renderer/` — утка: анимации, поведение, пузырь с текстом, звуки (синтезируются через WebAudio, файлов нет).
- `src/shared/duck-art.js` — утка рисуется кодом по пикселям; из этого же кода делаются иконки (`npm run icons`).
- `extension/` — расширение для Chromium-браузеров.
